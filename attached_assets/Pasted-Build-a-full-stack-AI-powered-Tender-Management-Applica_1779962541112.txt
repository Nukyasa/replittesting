Build THREE scrapers, each in its own file:

1. /scrapers/ejnScraper.js
   Source: https://www.ejn.gov.ba/
   BiH e-Javne Nabavke — main FBiH+RS portal
   Scrape: open tenders, all pages, with documents

2. /scrapers/referenceScraper.js  
   Source: https://tender.serapiondev.com/
   Login with credentials above, scrape all tender data
   This is the primary reference for data structure

3. /scrapers/unScraper.js
   Source: https://un-tenders.com/
   Filter for tenders relevant to Bosnia/Southeast Europe

Each scraper must:
  - Use Playwright in headless mode
  - Handle pagination automatically (follow "next page" until none)
  - Extract per tender:
      externalId, title, contractingAuthority, description,
      category, cpvCodes (if available), estimatedValue, currency,
      publicationDate, deadline, tenderType, entity (FBiH/RS/BD),
      status, sourceUrl, documentUrls[]
  - Download PDF/DOC documents to /uploads/{tenderId}/
  - Parse PDF text using pdfjs-dist, store in Document.parsedText
  - Upsert by externalId (skip if unchanged, update if modified)
  - Log run to ScraperLog table
  - Handle errors with 3-retry logic + exponential backoff
  - Emit SSE events (Server-Sent Events) so frontend shows live progress

Cron schedule:
  - ejnScraper:       every 2 hours  ("0 */2 * * *")
  - referenceScraper: every 4 hours  ("0 */4 * * *")
  - unScraper:        once daily at 6am ("0 6 * * *")
  - dailyDigest AI:   every day at 7am  ("0 7 * * *")

DATABASE SCHEMA (Prisma + PostgreSQL)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

model Tender {
  id                String    @id @default(cuid())
  externalId        String    @unique
  source            String    // ejn | reference | un
  title             String
  description       String?   @db.Text
  contractingAuth   String
  category          String
  cpvCodes          String[]
  estimatedValue    Float?
  currency          String    @default("KM")
  publicationDate   DateTime
  deadline          DateTime
  tenderType        String    // open | restricted | negotiated
  entity            String    // FBiH | RS | BD | International
  status            String    @default("open")
  sourceUrl         String
  documents         Document[]
  aiAnalysis        AiAnalysis?
  userTenders       UserTender[]
  notes             Note[]
  createdAt         DateTime  @default(now())
  updatedAt         DateTime  @updatedAt
}

model AiAnalysis {
  id                  String   @id @default(cuid())
  tenderId            String   @unique
  tender              Tender   @relation(fields: [tenderId], references: [id])
  summary             String   @db.Text
  keyRequirements     Json     // string[]
  eligibilityCriteria Json     // string[]
  risks               Json     // {risk: string, severity: low|medium|high}[]
  opportunities       Json     // string[]
  redFlags            Json     // string[]
  estimatedWorkload   String
  suggestedApproach   String   @db.Text
  relevanceScore      Float    // 0–100
  relevanceTags       String[]
  competitionLevel    String   // low | medium | high
  successProbability  Float    // 0–100
  insuranceRelevance  String   @db.Text  // specific analysis for insurance company
  requiredDocs        Json     // string[] — checklist of required documents
  analyzedAt          DateTime @default(now())
  analysisVersion     String   @default("1")
}

model Document {
  id          String   @id @default(cuid())
  tenderId    String
  tender      Tender   @relation(fields: [tenderId], references: [id])
  name        String
  originalUrl String
  localPath   String?
  fileType    String   // pdf | doc | docx | xlsx
  parsedText  String?  @db.Text
  fileSize    Int?
  createdAt   DateTime @default(now())
}

model User {
  id             String       @id @default(cuid())
  email          String       @unique
  password       String
  name           String
  role           String       @default("user") // admin | user | viewer
  department     String?      // e.g. "Nabavka", "Pravna služba", "IT"
  companyTags    String[]     // expertise tags for AI matching
  userTenders    UserTender[]
  notes          Note[]
  notifications  Notification[]
  createdAt      DateTime     @default(now())
}

model UserTender {
  id          String    @id @default(cuid())
  userId      String
  user        User      @relation(fields: [userId], references: [id])
  tenderId    String
  tender      Tender    @relation(fields: [tenderId], references: [id])
  status      String    @default("watching") // watching | in_progress | submitted | won | lost | skipped
  assignedTo  String?
  priority    String    @default("medium")   // low | medium | high | critical
  internalDeadline DateTime?
  createdAt   DateTime  @default(now())
  updatedAt   DateTime  @updatedAt
  @@unique([userId, tenderId])
}

model Note {
  id        String   @id @default(cuid())
  tenderId  String
  tender    Tender   @relation(fields: [tenderId], references: [id])
  userId    String
  user      User     @relation(fields: [userId], references: [id])
  content   String   @db.Text
  createdAt DateTime @default(now())
}

model Notification {
  id        String   @id @default(cuid())
  userId    String
  user      User     @relation(fields: [userId], references: [id])
  type      String   // new_tender | deadline_soon | ai_alert | digest | scraper_done
  title     String
  message   String   @db.Text
  tenderId  String?
  read      Boolean  @default(false)
  createdAt DateTime @default(now())
}

model ScraperLog {
  id               String    @id @default(cuid())
  source           String
  triggeredBy      String    @default("cron")  // cron | manual
  startedAt        DateTime
  completedAt      DateTime?
  tendersFound     Int       @default(0)
  tendersNew       Int       @default(0)
  tendersUpdated   Int       @default(0)
  docsDownloaded   Int       @default(0)
  errors           String?   @db.Text
  status           String    // running | completed | failed
}

UX RULES & DISPLAY FORMATTING

  - Monetary: "280.000,00 KM" (BiH format, use toLocaleString('bs-BA'))
  - Euros: "85.000,00 EUR"
  - Dates: "DD.MM.YYYY." (e.g. "04.06.2026.")
  - Score: always integer, no decimals (Math.round())

AI Score badges:
  score ≥ 80  → navy bg #002d82, white text — "Odlično"
  score 60-79 → green bg, dark green text — "Dobro"
  score 40-59 → amber bg, dark amber text — "Srednje"
  score < 40  → gray bg, dark gray text — "Nisko"

Deadline badges:
  ≤ 3 days  → red bg, red text + "HITNO!" label
  ≤ 7 days  → amber bg, amber text
  ≤ 30 days → light yellow, normal text
  > 30 days → gray, muted text

Status badges:
  open     → green  "Otvoren"
  closed   → gray   "Zatvoren"
  awarded  → navy   "Dodijeljen"
  cancelled → red   "Poništen"

Competition badges:
  low    → green  "Niska konkurencija"
  medium → amber  "Srednja konkurencija"
  high   → red    "Visoka konkurencija"

Loading states:
  - Use skeleton loaders (gray animated pulse) not spinners
  - AI analysis: skeleton with 4-5 rows of different widths
  - Tender list: skeleton cards

  - Scraper finished: "Sinkronizacija završena — X novih tendera"

Empty states:
  - No tenders: navy icon + "Nema tendera. Pokrenite sinkronizaciju."
  - No analysis: "AI analiza u toku..." with progress bar
  - No notes: "Dodajte prvu napomenu za ovaj tender"

Mobile responsive:
  - Sidebar collapses to icon-only on <768px, full hamburger on <480px
  - Bottom navigation bar on mobile (4 icons: home, tenders, chat, profile)
  - Tables become card stacks on mobile

Keyboard shortcuts:
  - Cmd/Ctrl+K → global search modal
  - Cmd/Ctrl+S → sync all scrapers
